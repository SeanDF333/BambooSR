# Data card

`data/bamboosr_sim_benchmark_v1.h5` has 112,890 events at 11,289 simulated source positions, ten stochastic realizations per position. Its fixed grid-disjoint splits contain 90,330 training, 11,280 validation, and 11,280 test events. `lr` has 169 channels in the aligned physical PMT order, with PMT3 set to zero. `hr` retains all 1,261 channels, including the PMT3 region. Channel columns correspond row-by-row to `geometry/lr_ids`, `geometry/lr_centers`, `geometry/hr_ids`, and `geometry/hr_centers`. The active photocathode radii are 32 mm (LR) and 12.5 mm (HR). `geometry/query_mm` and `geometry/weights` provide 128 finite-area integration points per HR channel.

The generator samples a nominal 100–5,000 PE-equivalent light-yield scale, converts it into emitted optical photons using an empirical 6.5% factor, and propagates photons. Final LR and HR labels count the same photon landing coordinates within different photocathode disks. The nominal generation interval is **not** a bound on either final sensor total; paired totals need not match. The virtual HR geometry uses an R7057-scale 25 mm active photocathode footprint. It does not simulate that tube's quantum efficiency, collection efficiency, gain, or electronics chain.

`data/bamboosr_wall_run2_5583_v1.npz` is **a fixed preselected PandaX-4T Run 2 wall-event evaluation sample used in the BambooSR paper**. It contains only `lr_pe` with shape `(5583,169)` and sequential public `event_index` values. It is not the complete Run 2 dataset. The event list was fixed before applying any SR method, and every downstream method uses the same 5,583 events. These real events have no event-level true x,y coordinates. The parent candidate sample and original event identifiers are not included.

The project owner confirmed permission to release the wall sample on 2026-10-26; this confirmation and the chosen CC BY 4.0 data license are recorded in `RELEASE_DECISIONS.md` and `DATA_LICENSE.md`. The underlying institutional permission document is not included. Detector-response fidelity and transfer from simulated photons to real events are limitations of the benchmark.
