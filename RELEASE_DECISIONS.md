# Release decisions

On 2026-10-26, the project owner confirmed in this working conversation that
the fixed 5,583-event PandaX-4T Run 2 wall sample is authorized for public
release. The owner selected MIT for the released code and CC BY 4.0 for the
two versioned data files in `MANIFEST.json`.

This file records the owner's confirmation and selected terms. The underlying
collaboration or institutional authorization document is not bundled in the
repository. Anyone making the final public release should retain that record
with the project governance materials.

The code belongs in the Git repository. The data files are release assets
because the simulation H5 file exceeds GitHub's regular Git file limit.
Website work is deferred until the owner supplies a logo and visual direction.
